# Meowtivator

웹과 모바일 앱을 개발합니다. 최근에는 AI가 도구를 호출하다 실패한 작업을 어떻게 다시 이어갈지, 강의 대본과 음성을 어떻게 영상으로 만들지 실험하고 있습니다.

## 팀 프로젝트에서 맡은 작업

### FishLog · 로그아웃한 세션이 되살아나는 오류 수정

로그아웃 전에 보낸 요청의 응답이 뒤늦게 도착하면 앱이 사용자를 다시 로그인 상태로 표시했습니다. 응답이 현재 세션에 속할 때만 반영하도록 바꾸고, 오프라인으로 앱을 켰을 때는 유효한 세션을 유지하도록 했습니다. [수정 코드와 회귀 검사 · PR #20](https://github.com/FishLog-project/fishlog_fe/pull/20)

### 국민대 멋쟁이사자처럼 · 14기 모집 페이지 개발

지원자가 모집 일정과 트랙별 커리큘럼, FAQ를 한곳에서 볼 수 있도록 모집 안내 페이지를 구현했습니다. 여러 화면에서 반복되는 UI는 공통 컴포넌트로 분리했습니다. [구현한 화면과 코드 · PR #9](https://github.com/LikeLion-at-KMU/14th-Page/pull/9)
